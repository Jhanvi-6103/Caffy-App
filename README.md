# ☕ Caffy App : Coffee Ordering Android Application

## 📌 Overview
Caffy App is an Android-based coffee ordering application that allows users to browse coffee items, add products to a cart, and place orders smoothly. The app is designed with a clean and user-friendly interface and uses Firebase services for authentication and data management.

This project is developed using Java and Android Studio, following Object-Oriented Programming (OOP) principles.

## ✨ Features
- User Authentication (Sign Up / Login)
- Browse coffee products
- Add products to cart
- Place coffee orders
- Product image handling
- Real-time data updates
- Clean and simple UI


## 🛠️ Tech Stack
- **Programming Language:** Java  
- **IDE:** Android Studio  
- **UI Design:** XML  
- **Backend Services:** Firebase  



## 🔥 Firebase Services Used
- **Firebase Authentication** – Secure login and signup
- **Firebase Realtime Database** – Store and manage products and orders
- **Firebase Storage** – Store and retrieve product images



## 📱 App Modules
- **Authentication Module** – Handles user login and registration
- **Product Module** – Displays coffee items with images
- **Cart Module** – Add and manage selected items
- **Order Module** – Place and store user orders
